What are Internet technologies?

Internet technologies help us share information and create web pages that people can explore using a browser. This sample website demonstrates fundamental HTML5 elements.

Three important web technologies

  • HTML structures page content.
  • CSS styles colors, spacing, and layout.
  • JavaScript adds interactive behavior.
